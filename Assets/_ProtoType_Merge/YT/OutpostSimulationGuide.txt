거점 모의전

1. OutpostSimulationScene.unity를 열고 Play합니다.
   메뉴 Tools > YT > Open Outpost Simulation으로도 열 수 있습니다.
2. 전투 대상: 1구역 은행강도 거점전(인질 구출 / 정면 돌파 / 루미나 폭주), 빌런협회 율리아전.
3. 영웅을 1~6명 선택하고 레벨, 장비, 시작 HP 비율을 설정합니다.
   위에서부터 실제 전투의 아군 배치 순서입니다. 장비는 기본 강화 단계입니다.
   스킬 해금, 능력치, IP 상한은 현재 메인 성장표를 따릅니다.
4. 배틀 모드: 메인의 정상 턴 순서, 적 AI, 스킬 비용, 사망 및 승패 판정을 사용합니다.
5. 프리 모드: 영웅 턴만 / 적 턴만 / 정상 턴 순서를 선택합니다.
   양 진영의 전투 유닛은 HP 1 미만으로 내려가지 않으며, 매 턴 IP 회복을 선택할 수 있습니다.
   영웅 스킬은 본게임과 같은 스킬 패널에서 선택하고 대상을 클릭합니다.
   적 턴만 모드에서는 왼쪽 패널에서 행동할 적, 보유 스킬, 대상을 직접 선택하고
   선택 스킬 재생 버튼을 누릅니다. 자동 공격하지 않으며, 한 번 재생한 뒤 입력을 기다립니다.
   정상 턴 순서 모드의 적은 본게임 AI로 스킬을 사용합니다. 배속 버튼도 본게임과 같습니다.
   회복 버튼은 행동이 진행 중이지 않을 때 생존 유닛의 HP/IP를 회복합니다.
6. 상단 설정으로 버튼 또는 전투 결과 확인으로 설정 화면에 복귀합니다.
   같은 Play 세션에서는 직전 편성, 성장, 전투 대상, 모드를 유지합니다.

밸런스 연결
- 전투는 복사된 전투 씬이 아닌 메인의 TmpBattleScene에서 실행합니다.
- 각 Play 시작 시 Resources/GameManager의 기본 탐사씬에 연결된 데이터 카탈로그 참조를 가져옵니다.
  수치를 복제한 모의전 전용 테이블은 만들지 않습니다.
- 적 레벨은 본게임과 같이 저장된 구역 레벨(있을 때) 또는 편성 평균 레벨을 사용하고,
  이벤트 전투 테이블의 최소/최대 레벨로 제한합니다. 구역 레벨을 새로 저장하지 않습니다.
- 아군은 SimulationUnitFactory와 UnitStatCalculator로 생성하는 임시 데이터입니다.
  실제 영웅 성장, 보상, 점령 상태는 모의전 결과로 저장하지 않습니다.
- 프리 모드의 진영 제한은 자발적 턴에 적용됩니다. 반격과 상태 효과는 본게임 규칙을 따릅니다.
- 이 씬은 Editor에서 직접 Play하는 작업용 씬입니다. 플레이어 빌드에서 사용하려면
  OutpostSimulationScene을 Build Settings에 추가해야 합니다.

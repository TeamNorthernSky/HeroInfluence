# 전투 비주얼 테스트씬

씬: `Assets/_ProtoType_Merge/JC/JC_TestScenes/z_JC_BattleVisualTestbed.unity`

Unity에서 씬을 단독으로 열고 직접 Play합니다. Build Settings 등록이나 탐사씬 진입은 필요하지 않습니다.
기존 `TmpBattleScene`의 UI·턴 진행·그리드·배경을 복제하고 테스트 전용 시작 처리를 연결했습니다.

## 기본 조건

- 히어로 10001~10004 네 명. 현재 데이터에서는 레벨 4이며 기본 스킬 네 종이 모두 해금됩니다.
- 히어로 데이터는 시뮬레이션 데이터 생성기를 이용한 임시 객체입니다. 저장소에 등록하지 않습니다.
- 탐사 초기 진형과 같은 아군 논리 셀 5, 1, 3, 2에 배치합니다. 10001은 전열 중앙, 10002·10004·10003은 후열 순서입니다.
- 테스트 전용 `BattleTestbed_UnitPrefabCatalog.asset`으로 정상 모델이 있는 Lower/Middle/AdvancedMonster 세 종을 두 마리씩 섞어 여섯 셀에 배치합니다.
- 적 후보는 데이터뿐 아니라 활성 메시·재질·Animator 컨트롤러와 단일 전투 캐릭터/적 스크립트 구성을 검사합니다. 내부 모델이 없거나 전투 캐릭터가 중복된 프리팹은 제외합니다.
- 일반 피해는 HP 1 아래로 내려가지 않고 0.25초 후 최대 HP로 회복합니다. 상태이상과 실제 피격 연출은 유지됩니다.
- 아군 IP는 매 프레임 최대치로 보충합니다. 스킬의 대상 조건(부활 대상 등)은 기존 규칙을 따릅니다.
- 일반 전투 시작·보상·저장·복귀를 담당하는 `BattleSceneManager`와 기존 치트는 이 복제본에서 비활성입니다. 도주·시스템 메뉴 버튼도 비활성입니다.

## 단축키

| 키 | 동작 |
|---|---|
| Z | UI·턴·유닛·진행 중인 연출을 정리하고 새 전투를 시작합니다. 적 배치는 유지하고 자동 전투/배속은 기본값으로 되돌립니다. 배경·카메라·조명은 재생성하지 않습니다. |
| G | 첫 히어로(저스티스)를 실제 사망 처리합니다. 행동/턴 안내 중이면 완료 후 처리합니다. 반복 입력으로 다른 아군까지 죽이지 않습니다. 정상 부활 스킬 또는 Z로 되돌립니다. |

부활 스킬의 전투당 사용 제한 등은 유지합니다. 반복해서 부활 연출을 볼 때는 Z로 새 전투를 시작합니다.

## 조절 위치

- `JC_BattleVisualTestbed`: 회복 지연, 적 배치 시드, 아군 구성/논리 셀, 화면 안내.
- `JC_Environment`: `ENV_BattleTestbed.asset`. 전용 하늘 재질을 사용합니다. 프로파일의 기존 적용 버튼으로 편집 화면에 반영할 수 있습니다.
- `Ground`: `Ground_BattleTestbed.mat`. 기존 PBR 값을 복사한 상태이며 아직 광택/툰 표현을 변경하지 않았습니다.
- `JC_Global Volume`: `PostProcess_BattleTestbed.asset`.
- `Main Camera`: 구도 조절. Z 초기화에도 위치와 설정을 유지합니다.

씬 저장 시 조명 프로파일을 한 번 적용했으므로 Play 전에도 HDRI·태양광 설정이 들어 있습니다. Scene View의 Scene Lighting 토글은 켜 두어야 합니다.
Play 중 씬 오브젝트에 가한 편집은 Unity의 기본 동작대로 Play 종료 시 되돌아갑니다. Z가 보존하는 범위와 Play 종료 시 보존은 다릅니다.

`JC_Testbed_BattleRuntime.prefab`은 Z 초기화용 UI/전투 구성입니다. 이 프리팹을 씬에 여러 개 배치하면 그리드와 매니저가 중복됩니다.
컨트롤러와 첫 배치/초기화용 양쪽 스포너는 모두 테스트 전용 등록표를 사용합니다. 적 추가 시에도 같은 등록표를 수정합니다.
캐릭터·스킬/VFX 자산은 실전과 같은 원본을 참조합니다. 이 씬만을 위한 변경은 복제한 환경 자산에서 시작합니다.
탐사 건물 색상 자동 연동 및 새 툰 셰이더는 아직 적용하지 않았습니다.

## 확인 상태

컴파일, 씬 연결/누락 스크립트, 12개 고유 셀, 임시 히어로 레벨·스킬·IP 비용, 적 시드 재현 검사를 통과했습니다.
적 메시/진형 수정 후에는 편집 모드의 임시 씬에서 실제 PlayerSpawner/EnemySpawner로 4명+6명을 생성해, 탐사 기본 진형과 적 모델/Animator·셀 점유·전체 전투 캐릭터 10개를 확인했습니다. 이전에 문제가 있던 빌런 프리팹 5종은 강화된 검사에서 모두 거절됩니다.
편집 모드의 별도 임시 객체로 피해 표시·지연 회복·치명타 불사·IP 보충·G 사망 유지·일반 부활 후 불사 재적용·제약 해제를 검증했습니다.
실제 UI 조작과 애니메이션 도중 Z/G 동작은 사용자 Play 검수 대상입니다.

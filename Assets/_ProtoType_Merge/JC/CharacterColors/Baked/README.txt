일반 빌런 몸체 색상 베이크 저장소

탐사·튜토리얼 탐사: JC_Environment → JC_VillainBodyColor
일반 전투: 씬 루트의 JC_VillainBodyColor

색상값은 플레이 중 즉시 반영됩니다. ‘검은 영역 보기’와 ‘원본 비교’로 확인하세요.
플레이 종료 전에 ‘현재 값을 프로필에 저장’을 눌러 조정값을 보존하세요.
‘저장값 다시 적용’은 저장하지 않은 조정값을 버리고 공용 프로필을 불러옵니다.
‘보정 텍스처 베이크 · 프로필 저장’은 현재 임포트 해상도(기본 2048×2048)의 새 PNG를 이 폴더에 저장하고 연결까지 보존합니다.
영역 표시·원본 비교·씬 조명·그림자는 베이크하지 않으며 원본 텍스처를 덮어쓰지 않습니다.
공용 프로필은 지정된 탐사·튜토리얼·일반 전투에 적용합니다. 이미 열려 있는 다른 조절기는 저장값 다시 적용 또는 씬 재진입 시 갱신됩니다.
무기·아놀드·보스전 유닛과 빨강·보라 등 유색 부분은 제외합니다.
베이크 후 조정값이 달라지면 실시간 미리보기로 전환합니다. PNG 파일 삭제는 연결된 프로필을 확인한 뒤 수행하세요.

‘검은 몸체 재질 반응’에서 반사광 강도(0~4), 광택·매끄러움(0~1), 메탈릭(0~1)을 실시간 조절합니다.
반사광 1은 기본 배율입니다. 광택 0은 넓고 거친 반사, 1은 작고 선명한 반사이며 메탈릭 1은 금속입니다.
이 값도 ‘현재 값을 프로필에 저장’으로 탐사·일반 전투에 공유합니다. 기본색 PNG에는 포함하지 않으므로 재질 조절만 바꿀 때는 재베이크가 필요 없습니다.
‘원본 비교’는 색상과 재질 보정을 함께 끕니다. ‘재질 조절 사용’을 끄면 색상 보정은 유지하고 기존 재질 반응으로 돌아옵니다.

## 보스 재사용 절차

1. 별도 `JcContactShadingProfile`을 만들고 보스의 원본 대상 재질과 접점 구간을 지정합니다. 구간 좌표는 배경 루트의 로컬 좌표입니다. 은행 프로필을 보스와 공유하지 않습니다.
2. 기존 보스 재질 관리자가 생성한 **복제 재질**을 사용합니다. `Initialize(profile, backgroundRoot)` 후 `RegisterMaterial(preview, original)`을 호출하고 마지막에 `ApplyDraft()`를 호출합니다.
3. 재질 생성·교체·파괴는 기존 재질 관리자가 계속 담당합니다. 공통 조절기는 등록된 미리보기 셰이더만 바꾸며, 비활성화 시 등록 당시 셰이더를 복원하고 접점 강도를 0으로 지웁니다. 은행은 재질 소유자가 접점·툰 호환 셰이더를 먼저 지정하므로 접점을 꺼도 툰은 유지됩니다. 재질 관리자가 복제본을 다시 만들면 새 복제본을 등록해야 합니다.
4. 현재 제공 셰이더는 URP 14.0.12 Lit용입니다. 다른 셰이더를 쓰는 보스 재질을 임의로 Lit으로 바꾸지 마세요. 해당 셰이더의 PBR 계산 전에 `JcApplyContactShading(albedo, positionWS)`를 연결하는 별도 검토가 필요합니다. 현 조절기는 URP Lit 원본만 허용합니다.
5. 배경 이동·회전·균일 배율 변경은 루트 행렬로 따라갑니다. 비균일 배율에서는 각 축의 월드 번짐 폭도 배율에 따라 달라집니다. 움직이는 캐릭터, 공용 색상표, 카메라, 라이트에는 연결하지 않습니다.

# 캐릭터 스킬 Inspector 작업대

갱신: 2026-09-18 · 작업 20260918-f1cf6ff887

## 사용

1. `z_JC_PreViewsScene_2`(저스티스), `3`(블랙불릿), `4`(루미나), `5`(네코밍)을 엽니다.
2. Hierarchy의 **JC_스킬작업대** 아래에서 `Q_스킬명` 등 원하는 오브젝트를 선택합니다. 씬마다 QWERASDF 8개입니다.
3. Inspector에서 차징·비행·착탄 등 부품의 **설정 에셋**을 펼쳐 직접 조절합니다. 기존 `.asset` 파일을 찾는 대신 이곳에서 같은 에셋을 편집합니다.
4. Play 중 **전체 스킬 선택** 후 Game 뷰에서 대상을 클릭하면 실제 시전합니다. 기존 QWERASDF 입력도 유지됩니다. **부품 재생**은 해당 재료만 검사하며 피해·회복 판정을 실행하지 않습니다. 차징 부품은 **발사 신호**, 종료는 **부품 중단**을 사용합니다.
5. 결과가 좋으면 **이 설정 저장**, 미저장 조절을 취소하려면 **저장값 복원**을 누릅니다. 프리셋은 해당 에셋, 부품 컴포넌트는 그 프리팹 전체가 저장 대상입니다. 일반 Unity 저장도 에셋 변경을 저장할 수 있습니다. Play 종료만으로 공용 에셋 조절값이 취소되지는 않습니다.

값은 다음 생성·재생부터 적용됩니다. 일부 살아 있는 효과에는 즉시 반영하지만, 이미 시작한 시간표 전체를 되감지는 않습니다. 변경 후 다시 시전하는 것이 확인 기준입니다.

## 조절 위치

| 대상 | 조절 방법 |
|---|---|
| 기존 프리셋이 있는 부품 | 부품 아래 프리셋을 펼쳐 색·크기·시간 등을 수정 |
| 임시 부품에 프리셋이 없는 항목 | **부품 자체 설정 · 고급**의 실제 컴포넌트와 재질 |
| 전투가 직접 이동시키는 투사체 | **실제 시전 · 투사체 이동**의 속도·궤적·높이·잔상. 속도 변경은 실제 도착/피해 시점에도 영향 |
| 블랙불릿·Paw 조립 | 아래 **부품 조립 시간**. 프리셋 기준 시간에 단계별 delay를 더함 |
| Basic 따름이 켜진 네코밍 설정 | 안내된 항목은 Basic 프리셋에서 수정하거나 따름을 해제 |

부품 자체 설정에서 프리셋과 중복되는 값은 프리셋이 우선합니다. 외부 이동형 부품의 자체 duration/arcHeight는 단독 검사에 사용되며 전체 시전 이동은 위 투사체 설정을 사용합니다.

## 공유 범위와 캐릭터별 처리

- 프리뷰와 **TmpBattleScene은 동일한 공용 연출·부품·프리셋을 사용**합니다. 프리뷰 조절 결과가 전투에도 반영되며 별도 이식/복사 과정이 없습니다. TmpBattleScene 파일 자체를 고치지는 않았습니다.
- 저스티스 크래시의 임시 이동 궤적은 Dash와 프리셋·재질을 분리했습니다. 크래시 착탄은 기존 `HeroSkill/Justice/Crash/Presets/FX_JusticeCrash_*.asset`를 그대로 사용합니다.
- 저스티스 S 용권풍은 강화 컨테이너가 강화판 Arc/Point/WindArcs/Shard를 생성하도록 연결을 교정했습니다. 강화 파편 변형을 추가했으며, A→S→A 실제 시전에서 기본 청색과 강화 적색이 섞이지 않는 것을 확인했습니다.
- 블랙불릿 8개 사격 프리셋의 적용 대상은 각 스킬의 총구·비행·착탄 3개 부품입니다. 기존 단일 샘플 프리팹에 잘못 기록되지 않도록 적용 경로를 교정했습니다. 비행/착탄 생성 시점은 해당 프리셋 시간에서 읽습니다.
- 루미나 기본/강화별 프리셋 8개와 런타임 바인더를 추가했습니다. 분리된 차징·비행·착탄도 자기 프리셋을 읽으며, 기존 전역 프리셋 편집기가 이 부품에 덮어쓰지 않도록 제외했습니다. 플레어의 차징·비행은 자체 컴포넌트와 전용 재질로 조절합니다.
- 네코밍의 기존 완성 부품 프리셋은 실제 참조를 그대로 노출합니다. Paw 등장/워프/도착 조립 시간은 Paw 마스터 프리셋 변경을 따릅니다. TAO의 Meteor는 **교체 후보**이며 현재 전체 시전은 Barrage를 사용합니다.
- 임시 틀을 최종 VFX·애니메이션으로 완성한 작업은 아닙니다. 카메라 연출·사운드 매니저·신규 애니메이션 제작은 이번 범위에 포함되지 않습니다.

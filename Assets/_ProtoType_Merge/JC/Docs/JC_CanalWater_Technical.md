# JC 카툰 수면 · 실시간 조절

갱신: 2026-10-14 / Unity 2022.3.62f3 · URP 14.0.12.

## 조작 위치와 저장

`JC_WorldDressing > JC_Water`에서 물색, 수면 포말, 움직임, 물가 포말, 조명을 조절합니다. 물 전용 객체는 기존 `JcExploreDetailOverlay`가 준비하며 씬에 별도 저장할 필요가 없습니다.

- 변경값은 즉시 표시용 재질에 반영됩니다. 편집 모드와 플레이 모드 모두 같은 적용 경로를 사용합니다.
- `현재 값 저장`: `Resources/JC_Water_Default.asset`에 저장합니다. 플레이 중에도 명시적으로 저장한 값은 종료 후 유지됩니다.
- `저장값 불러오기`: 임시 조절값을 저장된 값으로 되돌립니다.
- `애니메이션 일시정지`: 이동·형태 변화·물가 움직임을 함께 멈춥니다. 저장 프로필에는 포함되지 않습니다.
- 저장하지 않은 조절은 씬 재로드·스크립트 재컴파일 등의 객체 재생성 시 사라질 수 있습니다.
- Inspector에서 물을 선택하면 편집 모드 애니메이션을 갱신합니다. 플레이 테스트는 사용자가 직접 수행합니다.

## 구조

수면 메시, 물가 거리(UV1.x), 교량 하부 연결 및 수로 방향 지도는 기존 베이크를 재사용합니다. 수면과 호안이 같은 메시 안의 별도 재질 슬롯이므로 수면 슬롯만 갱신합니다.

`JcWaterController`는 베이크 재질마다 표시용 재질 하나를 생성하고 해당 수면들이 공유하게 합니다. 베이크 원본 재질과 다른 씬의 공유 재질은 수정하지 않습니다. 비활성화 시 기존 재질 슬롯을 복원하고 임시 재질을 해제합니다. 베이크 재표시·교체 시 재연결하며 현재 임시 조절값은 유지합니다. 지형 원본 복귀 시에는 물 제어 대상도 해제됩니다.

`JcWaterProfile`은 별도 저장 설정입니다. 기존 탐사 프로필의 물 외형 필드는 과거 직렬화 호환용으로 보존하고 기본 Inspector에서는 숨깁니다. 기존 수로 방향 필드는 방향 지도 생성의 하류 기준으로 유지합니다.

## 셰이더

기존 `CalmCanalWater.shader`의 GUID와 이름을 보존했습니다. 수면은 Opaque, ZWrite On, alpha=1입니다. 월드 X/Z 좌표의 절차적 무늬에 수로 방향장을 적용하고 두 이동 위상의 연속 형상장을 혼합한 뒤 포말을 한 번만 판정합니다. 분포는 형상을 다시 잘라내지 않고 투명도로 적용합니다. 포말 투명도는 불투명 물 바탕과의 색상 합성에 사용합니다. 화면 미분값으로 가장자리와 원거리 미세 무늬를 보정합니다. 물가 포말은 UV1 거리와 불규칙한 끊김을 사용합니다.

실시간 컨트롤러가 연결되면 독립 시간을 사용하고, 컨트롤러가 없는 전투 배경 등은 Unity 기본 시간으로 움직입니다. 베이크 저장 시 독립 시간 사용을 해제하여 전투 배경 추출본이 정지하지 않도록 합니다. 같은 셰이더를 사용하는 전투 배경도 카툰 표현으로 바뀌지만 탐사의 임시 인스펙터 값이 다른 배경 재질을 직접 변경하지는 않습니다.

현재 모델은 시각적 흐름입니다. 유체 시뮬레이션, 굴절, 수중 투시, 파도 높이 변형, 교각 물보라는 포함하지 않습니다. 포말 길이는 흐름 방향의 이웃 샘플을 평균하여 표현하며 이동 방향은 수로 방향장을 따릅니다.

## 수정

- BgColorModifier.Rebind가 파괴된 Renderer를 건너뜁니다. 원래 캐시에서 찾은 항목을 바로 r.gameObject로 읽던 것이 보고된 예외의 직접 원인이었습니다.
- BgColorRoot는 활성화·비활성화·파괴 시 캐시를 비우고, 대상 루트/플레이 상태가 바뀌거나 캐시 안에 파괴된 렌더러가 있으면 즉시 다시 찾습니다.
- 씬 전체 검색은 유효하고 로드된 씬에서만 수행합니다. 원래 재질 속성을 복원할 때 대상 렌더러의 재질 슬롯이 이미 제거된 경우도 건너뜁니다.
- 건물을 씬에 직접 배치하는 방식은 유효합니다. 직접 배치인지 생성 방식인지보다 캐시와 임시 리소스의 수명·소유권을 맞추는 것이 핵심입니다.

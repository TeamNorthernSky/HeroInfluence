## 색상과 기능

베이크 명암·AO·버텍스 색상 없이 팔레트 기본색만 사용합니다. 기존 조절 방식과 같은 14개 부위 ID를 사용하며, 해당 건물에 없는 부위는 실제 메시 영역이 없습니다. 기본값은 새 팔레트이며 기존 프로필 파일은 보존했습니다. 기존 ID와 일치하는 부분은 구형 프로필을 불러올 수 있고, 새로 분리한 부위는 기본값으로 시작합니다.

특수 건물 3종도 색상 조절기에 추가했습니다. 기존 일반 건물의 대상 부모 범위를 유지하면서, 특수 건물 컨트롤만 같은 씬 전체의 전용 재료를 찾도록 옵션을 추가했습니다. 재료가 바뀌면 다음 갱신에서 즉시 재연결하여 점령 색상이 이전 상태로 남지 않도록 했습니다.

은행·협회의 중립/아군/적군 재료는 기존 상태 팔레트의 색을 새 UV의 창·문 유리 영역에 적용합니다. 게임 상태·상호작용·영역 키·콜라이더·생성 로직은 유지하고 복사한 기능 프리팹의 시각 참조를 교체했습니다. 기존 DH 타일 에디터 코드와 원본 기능 프리팹/카탈로그는 수정하지 않았습니다.

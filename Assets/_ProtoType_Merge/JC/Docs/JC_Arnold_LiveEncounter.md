# 아놀드 실제 조우 전투 연결·검증 기록

- 작업: `20261012-487521c1a4`, 2026-10-12
- 대상: `JC_Testbed`, Unity 2022.3.62f3, `DHScene_3` → `TmpBattleScene`
- 요청: 실제 탐사에서 아놀드 조우 전투를 연결하고 Play Mode로 검증. 수면 세부 폴리싱과 배포 빌드는 이번 실행에서 제외.

## 적용

`CombatSceneEntryController`가 기존 전투 진입 직전에 `JcArnoldBattlePresentation.Prepare`를 호출합니다. 1구역 이벤트 전투 `BE161`만 적용하며, 참가자·스킬·보상·결과·복귀는 기존 전투 시스템을 사용합니다.

탐사씬이 살아 있을 때 실제 파티 위치, 적 배치 키에 해당하는 추적자의 위치, 현재 드레싱이 반영된 외형을 읽고 기존 동적 배경 알고리즘으로 전투 공간을 만듭니다. 탐사 지형이나 이동 판정은 수정하지 않습니다. 배경 생성 실패 시 경고를 남기고 기존 전투 배경으로 진입합니다.

탐사 건물의 런타임 색상 미리보기는 `RenderTexture`이므로 별도 GPU 복사본을 보관하도록 `JcDynamicBattleOutput`을 수정했습니다. 원본 탐사씬이 종료되어도 전투 배경의 텍스처가 유지되며, 복사본은 전투 종료 시 해제됩니다.

실제 전투씬에는 저장된 `JC_BattleCamera_Default`의 A/B 구도와 기존 뷰(F8)를 적용합니다. 이동 시간은 0.65초이며 위치·회전·FOV를 선형 보간합니다. `JC_BattleHud_Layout`은 테스트씬에서 확정한 좌측 HUD/상단 턴 순서의 표시값만 실제 UI에 적용합니다. 원래 UI 컴포넌트와 이벤트 연결은 유지합니다. 씬 파일은 저장하거나 변경하지 않았습니다.

대화 교체 시 이전 대화의 종료 이벤트가 새 조우 모달을 닫고 적 식별자를 지우던 문제를 `ChatModalController.Begin`에서 수정했습니다. 새 종료 콜백과 이벤트 구독을 연결하기 전에 이전 대화를 끝냅니다. 처음에는 초기 대화를 남긴 테스트 조건에서 발견했으며, 수정 후 대화가 겹친 경우와 초기 대화를 정상 종료한 경우를 모두 확인했습니다.

## 검증 범위와 보존

- 등장까지의 대기 턴은 단축했습니다. 자연 발생 타이밍, 장시간 추적, 전투 밸런스는 이번 검증 범위가 아닙니다.
- 능력치 강화는 승리 분기 테스트의 런타임 객체에만 적용했습니다. 원본 테이블은 수정하지 않았습니다.
- 두 저장 JSON은 테스트 전 백업으로 복구했고 SHA-256 일치를 확인했습니다. 사용자가 조절한 수면·카메라 프로필은 편집하지 않았습니다.
- 전체 작업 트리의 `git diff --check`에는 기존 Unity YAML 공백이 있으므로 전체 통과로 간주하지 않습니다. 이번 수정 C#의 공백 검사는 통과했습니다.
- 임시 실행 코드의 파일 경로/형식명 오류는 테스트 중 해결했습니다. 프로젝트 컴파일 오류와 구분합니다.
